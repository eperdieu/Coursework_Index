## Coursework

### Networking Fundamentals (CIT 20200)
* OSI model and the seven step troubleshooting method
* Structured cabling (TIA/EIA 568), copper and fiber standards, termination, and cable testing
* Ethernet and wireless standards, wireless surveys, and wireless security (WPA2, WPA3, enterprise authentication)
* VLANs, network monitoring tools, and remote management (SSH, jump boxes, out of band management)
* Network security concepts: CIA triad, common attack types, DHCP and DNS spoofing, DMZ design
* Cloud networking: VPCs, gateways, security groups, infrastructure as code, and zero trust

[View folder](CIT_20200_Networking_Fundamentals)

### Cybersecurity and Network Programming (CIT 30900)
* Python tools for security work, including a firewall log analyzer, a domain and Shodan lookup tool, an exposure checker, and a regex based data cleaner
* Unit testing, command line tools, REST APIs, and bash scripting

[View folder](CIT_30900_Cybersecurity_Network_Programming)
