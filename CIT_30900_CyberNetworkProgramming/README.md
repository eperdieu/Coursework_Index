# CIT 30900: Cybersecurity and Network Programming

Purdue Polytechnic Institute, Fall 2024

Python scripting for security work: file handling, regular expressions, databases, APIs, command line tools, unit tests and bash.

## Projects
* [firewall_log_analyzer](firewall_log_analyzer): command line tool that analyzes firewall logs
* [domain_explorer](domain_explorer): looks up the IP and exposed services for a domain
* [employee_exposure_checker](employee_exposure_checker): checks employee records against an exposure API and drafts breach notices
* [phone_finder](phone_finder): cleans and searches phone number data with regex

## Note
Class data, assignment sheets and instructor starter code are not included. All data used in these projects was fictional.
