# OLS 37100: Project Management

Purdue University Indianapolis, Polytechnic Institute | Summer 2025

## About the Course

A course on planning and managing projects. The main project had the class act as project managers for a simulated nonprofit, building the planning documents and then managing the project through simulated updates.

## Topics

* Project scope statements
* Work breakdown structures and scheduling
* Budgeting and earned value management
* Group planning and team agreements

## Skills

Scope definition, WBS, scheduling, budget tracking, earned value analysis, working in project teams

## Note

No assignments or group documents are posted here. They include classmates' names and instructor material.
