# CIT 27000: Java Programming

Purdue Polytechnic Institute, Fall 2024

## About this class
An object oriented programming course taught in Java using NetBeans. Topics covered:
* Classes, objects, constructors and static vs instance members
* Inheritance and method overriding
* Interfaces and abstract classes
* Inner classes and local classes
* String handling
* Event handling with Swing timers
* Building a GUI application

## Team project
Built a Java banking application with a team of three. Requirements included at least 5 classes, 2 inheritance relationships, 3 association relationships and a GUI.
