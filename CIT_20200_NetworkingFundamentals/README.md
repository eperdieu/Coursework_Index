# CIT 20200: Networking Fundamentals

Purdue University Indianapolis, Polytechnic Institute | Fall 2024

## About the Course

An introduction to how networks are built, secured, and troubleshot, from physical cabling up through cloud networking. Coursework combined textbook chapters, written assignments, and simulated lab exercises.

## Topics

* OSI model and the seven step troubleshooting method
* Structured cabling (TIA/EIA 568), copper and fiber standards, termination, and testing
* Ethernet and wireless standards, wireless surveys, and wireless security
* VLANs, network monitoring tools, and remote management
* Network security concepts, common attacks, and DMZ design
* Cloud networking: VPCs, gateways, infrastructure as code, and zero trust

## Skills

Network design basics, physical troubleshooting, wireless security, network monitoring, cloud networking concepts
