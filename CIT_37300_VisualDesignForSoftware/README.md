# CIT 37300: Visual Design for Software

Purdue Polytechnic Institute

## Topics
* UI and UX design principles, including contrast, emphasis, and the golden rules of interface design
* Usability vs utility and heuristic review of real websites
* Figma: frames, components, constraints, grids, prototyping, and design handoff
* User research: target markets, ideal user personas, and tree diagrams for site structure
* Storyboards, wireframes, and prototypes for desktop, tablet, and phone
* Typography, mood boards, color, and art direction

## Team project
Redesigned a website for a fictional family farm audience with a partner, from user persona through wireframes to a clickable prototype.

## What is posted here
Two team deliverables: the ideal user persona and the site tree diagram. The persona is fictional. Weekly assignments and design files are not included.
